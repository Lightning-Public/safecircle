# SafeCircle Contest Assets

공모전 제출용 설명 자산입니다.

## Canonical assets
- `safecircle-ai-cloud-crisis-data.svg` — AI·클라우드·위기 데이터 활용
- `safecircle-public-private-collaboration.svg` — 민관협력 구조
- `safecircle-expected-impact.svg` — 기대효과

## CI rule
- 모든 자산의 SafeCircle 심볼은 `prototype/assets/logo-mark.svg`와 동일한 path/color 값을 사용합니다.
- 이미지 생성 모델이 로고를 다시 그린 결과물은 최종 제출 자산으로 사용하지 않습니다.
- 로고 색상: Blue #2F80ED / Green #35C98A / Orange #F2B134
- 문서 순서 번호(4., 5. 등)는 이미지 안에 넣지 않습니다.

## Notes
이 세 SVG는 이번 세션에서 만든 여러 이미지 시안 중 내용과 구성을 정리해 CI를 고정한 재사용 가능한 제출용 자산입니다.
